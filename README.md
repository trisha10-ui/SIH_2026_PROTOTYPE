# SIH_2026_PROTOTYPE
AI-based real-time stress &amp; trauma assessment module for victims/complainants using NHAA(14566)- SIH 2026,PS 26093(Team NeuraSakhi)

Prototype for SIH 2026 Problem Statement 26093 (Ministry of Social Justice & Empowerment).
Adds an AI-based real-time stress/trauma assessment layer to the National Helpline Against Atrocities (NHAA – 14566) portal, 
so emotional distress is detected early and escalated to a human officer when needed.
**Built as a working prototype: victim input → keyword-based stress scoring → escalation logic → officer dashboard.**
